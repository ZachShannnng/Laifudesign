# Web 原型 Skill

## 能力范围

- 响应式落地页
- 产品展示页
- 功能介绍页
- 关于我们页面
- 联系方式页面

## 设计原则

1. **移动优先**：从小屏幕开始设计，逐步扩展到大屏幕
2. **内容优先**：内容驱动布局，而非装饰性元素
3. **渐进增强**：核心功能在所有设备上可用，高级特性逐步添加

## 组件清单

- 导航栏（响应式，带汉堡菜单）
- Hero 区域（标题、副标题、CTA）
- 功能特性网格
- 用户评价/案例
- 页脚（链接、版权信息）
