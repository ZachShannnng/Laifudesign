# Dashboard Skill

## 能力范围

- SaaS 管理后台
- 数据分析看板
- 安全控制台、网关平台、业务运营台
- 表格、筛选、指标卡、图表、详情抽屉

## 设计原则

1. 信息密度优先，避免营销页式大 hero。
2. 采用清晰导航、筛选区、数据区、操作区。
3. 表格和指标必须可扫描、可比较。
4. 状态、风险、告警要用一致的语义色和标签。

## 输出要求

- 生成完整 HTML artifact。
- 默认桌面宽度 1440px 体验优先，同时保持 1024px 可用。
- 不把页面 section 做成嵌套大卡片。
