# SaaS Landing Skill

## 能力范围

- 产品官网首页
- 功能介绍页
- 定价页、客户案例页、下载/预约页面

## 设计原则

1. 首屏明确产品/品类和核心价值，不做抽象口号。
2. Hero 必须给出真实产品感，可用产品界面、流程或场景承载视觉。
3. 内容结构遵循：价值 -> 证据 -> 功能 -> 场景 -> 行动。
4. 移动端首屏必须露出下一段内容线索。

## 输出要求

- 生成完整 HTML artifact。
- CTA、导航、功能块、社会证明、页脚完整可用。
- 不使用空洞渐变背景替代产品表达。
