# Image Poster Skill

## 能力范围

- 社媒分享图
- 活动海报
- 产品封面
- 品牌宣传视觉稿

## 设计原则

1. 以单张画面构图为核心，建立强视觉焦点。
2. 文案层级清晰，避免装饰压过主题。
3. 明确尺寸比例：默认 1080x1350，可按用户要求调整。
4. 可用 CSS 和 HTML 构建可编辑海报，不调用外部图片生成命令。

## 输出要求

- 生成完整 HTML artifact。
- 画布尺寸稳定，适合截图导出。
- 不依赖 OD media 或任何外部 CLI。
