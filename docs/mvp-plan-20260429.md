# MVP Plan: Laifu Design - 最小可行版本

生成于: 2026-04-29
基于: /plan-ceo-review 审查 + Claude Code 架构分析

---

## 决策摘要

| 决策 | 选择 | 理由 |
|------|------|------|
| 实现方案 | **从零构建 + 智能体框架** | 基于 Claude Code 提取核心架构，完全控制 |
| 审查模式 | **SCOPE REDUCTION** | 务实优先，3-5 周快速验证 |
| MVP 范围 | **Web 版本最小化** | 先验证核心价值，桌面壳延后 |
| 架构定位 | **UI 设计智能体** | 不是 API 包装，是可扩展的智能体框架 |
| 模型策略 | **用户可配置** | 支持用户选择模型，不被单一供应商绑定 |
| API Key 存储 | **localStorage** | 简单快速，内网环境暂接受安全风险 |
| 错误处理 | **基础错误提示** | 必须做，否则用户体验不可接受 |
| 输入验证 | **跳过** | 最小版本先不处理 |

## MVP 范围（3-5 周）

### ✅ 必须做

| 功能 | 描述 |
|------|------|
| Web 版本 | React + Vite，浏览器运行 |
| 智能体框架 | DesignEngine + ModelClient + DesignTool 系统 |
| 可配置模型 | 用户可配置 API 地址/Key/模型 |
| AI 生成 UI | 自然语言 → HTML 流式预览（通过 GenerateUITool） |
| 设计系统配置 | 默认 **Lovable 设计系统**，支持用户自定义样式变量 |
| Lovable 集成 | 暖色调奶油背景、Camera Plain Variable 字体、内阴影按钮 |
| 导出 HTML | 包含 React + Babel CDN（通过 ExportHTMLTool） |
| 错误处理 | 超时重试 2 次，显示错误提示 |
| localStorage 存储 | API Key、模型配置、设计系统配置、对话历史 |
| **中止生成** | 发送按钮在生成时变为停止图标（⏹），点击中止流式输出，已输出部分保留 |
| **多行输入框** | textarea + 自动增高（max 5 行），Shift+Enter 换行，Enter 发送 |
| **对话历史管理** | 多会话切换、新建对话、删除对话、会话列表侧边栏，localStorage 持久化 |
| **迭代修改** | 增量修改模式（默认）：AI 基于当前 HTML 做局部修改；重新生成模式：用户显式说"重新做" |
| **代码查看/编辑** | 预览区工具栏"查看代码"按钮，切换到代码视图（语法高亮 + 可编辑），编辑后实时更新预览 |
| **设计系统即时预览** | JSON 编辑器"实时预览"开关，开启后变更自动应用（debounce 500ms） |
| **首次引导** | 检测 API Key 缺失，显示引导卡片跳转设置标签页 |
| **预设模板** | 空状态建议提示词扩展为可点击模板卡片（登录页、落地页、仪表盘） |
| **生成快照** | 每次成功生成自动保存快照到 localStorage（最多 10 个），预览区工具栏历史下拉 |
| **键盘快捷键** | Ctrl+Enter 发送、Ctrl+Shift+X 导出、Escape 停止生成 |

### ❌ 不做（延后）

| 功能 | 理由 |
|------|------|
| Electron 桌面壳 | Web 版本验证成功后再考虑 |
| 元素批注（点击+注释） | 用文字对话修改 + 代码编辑替代 |
| 更多 DesignTool | MVP 3个工具（GenerateUI, ApplyTheme, ExportHTML）足够 |
| 范例页面管理 | 设计师手动贴 HTML 到设计系统 |
| 设计系统导入导出 | 手动编辑 JSON |
| 多页面项目管理 | 单页面足够验证 |
| 输入验证 | 最小版本跳过 |

## 数据流（智能体版本）

```
用户输入 prompt
    │
    ▼
DesignEngine.submit(prompt)
    │
    ├── 构建设计上下文 (DesignContext)
    │   ├── 对话历史 (messages)
    │   ├── 当前 HTML (currentHtml)
    │   ├── 设计系统配置 (designSystem)
    │   └── 模型配置 (modelConfig)
    │
    ├── 判断修改模式
    │   ├── 有 currentHtml 且非"重新做" → 增量修改模式
    │   └── 无 currentHtml 或用户说"重新做" → 全新生成模式
    │
    ├── ModelClient.stream(messages)
    │   │
    │   ├── 解析流式输出
    │   ├── 检测 tool_use 调用
    │   └── 返回 StreamChunk
    │
    ├── 中止控制（随时可触发）
    │   ├── 用户点击 ⏹ 或按 Escape
    │   ├── DesignEngine.abort()
    │   ├── ModelClient 中止流式请求
    │   └── 已输出部分保留在消息历史
    │
    ├── 当检测到 tool_use 时
    │   │
    │   ├── 查找对应的 DesignTool
    │   │
    │   ├── GenerateUITool:
    │   │   ├── 输入: { prompt, pageType, currentHtml? }
    │   │   ├── 增量模式: 传入 currentHtml，AI 做局部修改
    │   │   ├── 全新模式: 不传 currentHtml，AI 从零生成
    │   │   └── 输出: { html, components, changeDescription }
    │   │
    │   ├── ApplyThemeTool:
    │   │   ├── 输入: { html, theme }
    │   │   ├── 处理: 应用设计系统
    │   │   └── 输出: { styledHtml }
    │   │
    │   └── ExportHTMLTool:
    │       ├── 输入: { html }
    │       ├── 处理: 打包为可运行 HTML
    │       └── 输出: { filePath, content }
    │
    ├── 将工具结果加入消息历史
    │
    ├── 保存快照到 SessionManager
    │   └── { timestamp, html, userPrompt }
    │
    └── 继续流式输出到 PreviewPanel
        │
        ▼
    实时渲染到 iframe
        │
        ▼
    完成 → 工具栏显示 🔄⛶📥</>⏱
    │
    ▼
    用户可: 导出 / 查看代码 / 查看快照 / 继续对话修改
```

## 错误处理

| 异常类 | 救援动作 | 用户看到 |
|--------|----------|----------|
| `TimeoutError` | 重试 2 次，仍失败则提示 | "API 调用超时，请检查网络连接" |
| `RateLimitError` | 显示提示，等待后重试 | "API 调用频率超限，请稍后再试" |
| `InvalidResponseError` | 显示错误详情 | "生成内容格式异常，请重试" |
| `AuthError` | 提示检查 API Key | "API Key 无效，请检查配置" |
| `NetworkError` | 显示网络错误 | "网络连接失败，请检查网络" |

## 已知风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| localStorage 暴露 API Key | 安全 | 内网环境暂时接受，MVP 之外加后端代理 |
| 智能体框架复杂度 | 开发风险 | 基于 Claude Code 验证过的架构 |
| 不同 API 格式兼容性 | 兼容性 | ModelClient 统一接口，逐步支持 |
| 输入验证缺失 | 稳定性 | 工具层面做基本验证 |
| 流式工具调用处理 | 技术难点 | 参考 Claude Code 的 QueryEngine 实现 |

## 设计决策（来自 plan-design-review + 架构分析）

### 布局规范
- **界面布局**: 侧边标签页 + 预览区
  - 左侧: 标签页面板（垂直标签切换）
    - 聊天标签: 会话列表 + 对话消息列表 + 输入区
    - 设置标签: 模型配置表单
    - 设计系统标签: 设计系统配置（JSON 编辑器）
  - 右侧: Preview 区域（iframe，始终可见）
  - 顶部: 无固定顶栏（标签页自带导航）

### 聊天消息规范（Lovable 暖色工作区风格）
- **用户消息**: 右对齐，#f7f4ed 奶油色背景卡片，1px solid #eceae4 边框，12px 圆角，#1c1c1c 文字，最大宽度 80%
- **AI 消息**: 左对齐，无边框纯文字，#5f5f5d 灰色，描述生成结果（如"已生成登录页面，包含邮箱输入和密码字段"）
- **工具调用**: 左对齐，#eceae4 左边框 2px 条纹，14px 灰色小字标注（如"GenerateUITool → 生成登录页面"），与 AI 消息视觉区分
- **预览联动**: AI 生成完成时，右侧预览区自动更新并滚动到顶部
- **流式输出**: AI 回复逐字显示，工具调用实时标注进度
- **时间戳**: 可选，14px #5f5f5d，悬停显示
- **中止生成**: 生成中发送按钮变为 ⏹ 停止图标，点击中止流式输出，已输出部分保留在消息区
- **多行输入**: textarea 自动增高（1-5行），Shift+Enter 换行，Enter 发送，底部提示"Shift+Enter 换行"
- **增量修改标注**: AI 增量修改时，工具调用标注显示"GenerateUITool → 修改标题颜色"而非"生成页面"，区分新建与修改

### 会话管理规范
- **会话列表**: 聊天标签顶部，"+新对话"按钮 + 折叠式历史会话列表
- **会话项**: 显示会话标题（取首条用户消息前 20 字）+ 时间（今天显示时间，更早显示日期）
- **会话切换**: 点击会话项切换，当前会话高亮（#eceae4 背景），预览区同步更新
- **会话删除**: 悬停显示 🗑 图标，点击删除（无确认，可撤销 3 秒）
- **会话标题**: 自动取首条用户消息前 20 字，用户可双击编辑
- **数据结构**: localStorage 存储 `sessions[]`，每项含 `{ id, title, messages[], currentHtml, createdAt, updatedAt }`
- **新对话**: 点击"+新对话"清空消息区和预览区，创建新会话

### 代码视图规范
- **入口**: 预览区工具栏 </> 按钮，点击切换代码/预览视图
- **代码视图**: 语法高亮（Monaco Editor 轻量版或 CodeMirror），可编辑
- **编辑生效**: 编辑后自动 debounce 500ms 更新预览（切回预览视图即可看到）
- **代码来源**: 显示 AI 生成的完整 HTML（含内联样式），非 iframe 渲染后的 DOM

### 预设模板规范
- **空状态显示**: 首次进入或新建对话时，消息区居中显示模板卡片
- **模板卡片**: 3 个可点击卡片（"登录页"、"落地页"、"仪表盘"），每个含图标 + 标题 + 一句话描述
- **点击行为**: 点击模板卡片自动填入输入框并发送（如"做一个登录页，包含邮箱输入和密码字段"）
- **样式**: #f7f4ed 背景 + #eceae4 边框，hover 时 rgba(28,28,28,0.04) 背景

### 生成快照规范
- **自动保存**: 每次成功生成（GenerateUITool 返回结果后）保存当前 HTML 快照
- **快照内容**: `{ timestamp, html, userPrompt }`
- **存储上限**: 每个会话最多 10 个快照，超出删除最旧的
- **入口**: 预览区工具栏 ⏱ 按钮，点击展开历史下拉
- **快照项**: 显示时间 + 用户提示词前 20 字，点击恢复到该快照

### 首次引导规范
- **触发条件**: localStorage 中无 API Key 时触发
- **引导卡片**: 聊天空状态区域显示引导卡片："开始前，先配置你的 AI 模型" + "前往设置"按钮
- **"前往设置"按钮**: 点击切换到设置标签页
- **配置完成后**: 返回聊天标签，引导卡片消失，显示正常空状态 + 模板卡片
- **跳过选项**: 引导卡片含"跳过"链接，点击后不再显示（localStorage 标记）

**时间维度设计**:
- **5 秒（直觉层）**: 奶油色暖背景 + 清晰的输入框 → "这工具友好、不吓人"
- **5 分钟（行为层）**: 完成第一次生成 → "这工具真的能用"

### 架构决策 ⭐ 新增
- **智能体框架**: 基于 Claude Code 提取的核心架构
  - DesignEngine: 会话管理引擎
  - ModelClient: 可配置模型客户端
  - DesignTool: 设计工具系统
- **工具驱动**: 通过 DesignTool 实现功能，不是直接输出
- **模型无关**: ModelClient 支持用户配置任何兼容的 API
- **类型安全**: 使用 TypeScript + Zod 确保工具输入输出正确

### 设计系统决策 ⭐ 新增
- **Lovable 设计系统**: 采用 Lovable 作为默认 UI 框架
  - 暖色调奶油背景 (#f7f4ed)，人性化的设计风格
  - Camera Plain Variable 字体，两个主要字重（400/600）
  - 浅深度系统，靠边框而非阴影定义边界
  - 内阴影按钮效果作为签名式细节
  - 完全适配 shadcn/ui + TailwindCSS 技术栈
- **可配置性**: 用户可以基于 Lovable 模板自定义设计系统
- **智能体集成**: 设计系统配置作为系统提示词的一部分，AI 生成自动遵循

### MVP 最低限度的响应式与无障碍（设计审查补充）
- **桌面最小宽度**: 1024px（低于此宽度显示"请使用更大屏幕"提示）
- **键盘导航**: Tab 键可切换标签页、输入框、按钮（基础可访问性）
- **颜色对比度**: Lovable 配色已符合 WCAG AA，无需额外检查
- **触控目标**: 按钮和标签页至少 32px 高度（Lovable 默认 8px 16px padding 已满足）

### 已确认的设计决策（2026-04-30）

**预览区工具栏**
- 决策: 导出 HTML、刷新、全屏三个按钮全加
- 理由: 用户选择完整工具栏，提升预览区交互能力

**移动端导航行为**
- 决策: MVP 只支持桌面，移动端显示"请使用更大屏幕"提示
- 理由: 专注桌面体验，移动端延后

**对话历史持久化**
- 决策: 使用 localStorage 保存对话历史
- 理由: 刷新后不丢失，保证工作流连续性

**导出格式**
- 决策: 导出完整 HTML + 内联 CSS（单文件可直接运行）
- 理由: 用户拿到文件就能用，无需额外配置
