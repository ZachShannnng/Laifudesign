# Mobile Soft

> Category: Mobile Consumer App
> Soft surfaces, generous touch targets, and friendly color contrast.

## Color

- **Primary:** `#14B8A6`
- **Secondary:** `#6366F1`
- **Background:** `#F8FAFC`
- **Surface:** `#FFFFFF`
- **Text:** `#0F172A`
- **Muted:** `#64748B`
- **Border:** `#E2E8F0`

## Typography

- Use 13/15/17/22/28/34 scale.
- Body copy must be readable on 390px mobile width.
- Prefer medium-weight headings, avoid overly heavy text.

## Layout

- Respect mobile safe areas.
- Bottom navigation and sticky primary actions are preferred.
- Touch targets should be at least 44px high.

## Components

- Use rounded but not childish surfaces.
- Inputs need clear labels and validation feedback.
