# Editorial Luxe

> Category: Editorial Brand
> Refined contrast, deliberate typography, and premium visual rhythm.

## Color

- **Primary:** `#7C3AED`
- **Accent:** `#D4AF37`
- **Background:** `#FAFAF9`
- **Surface:** `#FFFFFF`
- **Text:** `#18181B`
- **Muted:** `#71717A`
- **Border:** `#E7E5E4`

## Typography

- Display: Georgia or a high-contrast serif.
- Body: system sans-serif when dense readability matters.
- Use strong type hierarchy and generous line-height.

## Layout

- Hero sections should feel editorial, not card-based.
- Use asymmetry carefully while keeping content scannable.
- Avoid generic stock-like visual composition.
